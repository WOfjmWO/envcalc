基准含氧量折算浓度

计算公式
C折 = C实测 × (21 − O2基准) / (21 − O2实测)
注：当排放标准规定按实测浓度计或 O2实测 ≤ O2基准 时，按实测浓度计可不折算；燃煤/燃油/燃气锅炉等亦可按 GB 13271 附录 A 采用过量空气系数法。
请选择行业与设备类型后，将显示对应标准依据。
标准依据：GB 13271-2014、GB 13223-2011、GB 18485-2014、GB 18484-2020、GB 4915-2013、GB 28662-2012、GB 31570/31571/31572、GB 39726-2020 等（按所选行业/设备自动标注）。

过量空气系数折算浓度

计算公式（崂应式16 / 通用折算）
C折 = C实测 × α基准 / α实测 × K
参考标准：GB 13271-2014 附录A；崂应3012H-D式(16)；燃煤α基准=1.8，燃油=1.2，燃气=1.167

过剩空气系数（实测）

计算公式
α = 21 / (21 − O2)
参考标准：HJ/T 397-2007《固定源废气监测技术规范》

非甲烷总烃 干基浓度（HJ1332）

计算公式（湿基 → 干基）
C干基 = C湿基 / (1 − Xsw)
参考标准：HJ 1332-2023《固定污染源废气 总烃、甲烷和非甲烷总烃的测定 气相色谱法》。Xsw为体积分数小数(0~1)；若实测值已折算至标准状态，则结果为标干浓度。

油烟净化效率（GB18483）

计算公式（基于排放速率）
η = (C前Q前 − C后Q后) / (C前Q前) × 100%
参考标准：GB 18483-2001《饮食业油烟排放标准》；G前后=CQ (排放速率)

油烟基准风量折算浓度（GB 18483）

计算公式（GB 18483-2001 第 6.6 条）
c基 = c测 × Q测 / (n × q基)
c基：折算为单个灶头基准排风量时的排放浓度，mg/m³；Q测：实测排风量，m³/h；q基：单个灶头基准排风量，大/中/小型均为 2000 m³/h；n：折算的工作灶头个数。
参考标准：GB 18483-2001《饮食业油烟排放标准》第 6.6 条、表 2（小型/中型/大型餐饮单位油烟最高允许排放浓度均为 2.0 mg/m³，净化设施最低去除效率分别为 60%、75%、85%）。
2排放标准判定（GB16297 内插/外推）

排气筒高度 内插/外推法

计算公式（GB 16297-1996 附录B · 排气筒最高允许排放速率内插/外推）
内插法（表列 ha < h < ha+1）：
  Q = Qa + (Qa+1 − Qa) / (ha+1 − ha) × (h − ha)
外推法（h > 表列最高值 hb）：
  Q = Qb × ( h / hb )2
达标判定：实测排放速率 G ≤ Q
排气筒高度低于 15 m 时，其最高允许排放速率按外推结果再严格 50%（即取 Q/2）执行。两个排气筒之间距离小于该两个排气筒高度之和时，应合并视为一个等效排气筒计算。
参考标准：GB 16297-1996 附录B；外推结果对新源高度<15m 时再严格50%

等效排气筒(GB 16297 附录A)

计算公式（等效排气筒 · GB 16297-1996 附录A）
等效排放速率 Q = Q₁ + Q₂
等效排气筒高度 h = √[(h₁² + h₂²)/2]
位置 x = a·Q₂/Q（距排气筒1，沿连线）
当两排气筒排放同种污染物且间距 a < (h₁+h₂) 时，须合并为一根等效排气筒；三根以上依序与等效排气筒再取等效。Q 为排放速率(kg/h)，h 为排气筒高度(m)，a 为两筒间距(m)。
参考标准：GB 16297-1996《大气污染物综合排放标准》附录A（等效排气筒参数计算）
3体积与流量换算（GB16157/GB3095）

标态干烟气流量换算

计算公式（标态干烟气流量 · GB/T 16157-1996）
Qsnd = Qs × 273/(273 + ts) × (Pa + Ps)/101325 × (1 − Xsw)
Qs 工况湿烟气流量(m³/h)；ts 烟气温度(℃)；Pa 大气压、Ps 烟道静压，本卡两者均以 Pa 为单位（故分母取 101325 Pa）；Xsw 为烟气含湿量体积分数，以小数 0~1 输入。标准状态指 273 K、101325 Pa 的干烟气状态。
参考标准：HJ/T 397-2007；GB/T 16157-1996；Xsw为小数体积分数

体积换算（标况/参比）

计算公式（体积状态换算 · GB/T 16157-1996 / HJ 194 / HJ/T 55-2000）
废气标况（干基）：Vnd = V × 273/(273 + t) × (Ba + Ps)/101.325 × (1 − Xsw)
环境空气参比状态：Vr = V × 298.15/(273.15 + t) × P/101.325
无组织排放标况：Vs = V × 273/(273 + t) × Ba/101.325 × (1 − Xsw)
压力单位统一为 kPa，Xsw 以百分数(%)输入。废气标准状态为 273 K、101.325 kPa；环境空气按 HJ 194 采用 298.15 K、101.325 kPa 参比状态。无组织采样点位于敞开大气中，不叠加烟道静压 Ps。
废气/无组织:0℃·101.325kPa干基;环境空气参比:25℃·101.325kPa(GB3095附录A)

标况采样体积（崂应式4）

计算公式（崂应 3012H-D 式4 · 标况采样体积，GB/T 16157-1996）
Vnd = V × 273/(273 + ts) × (Ba + Ps)/101.325
V 为累积流量计示值给出的实际采样体积(L)；ts 为流量计前气体温度(℃)；Ba 为大气压、Ps 为流量计前表压，单位均为 kPa。结果为 273 K、101.325 kPa 下的标况体积(L)，用于计算颗粒物与气态污染物浓度。
崂应3012H-D说明书式(4)；Ba、Ps单位 kPa，标准 101.325 kPa

烟气工况流量（崂应式5）

计算公式（崂应 3012H-D 式5 · 工况烟气流量，GB/T 16157-1996）
Qs = 3600 × Vs × F
Vs 为烟道测定断面的平均流速(m/s)，F 为烟道断面积(m²)，系数 3600 为 s→h 换算，结果为工况湿烟气流量(m³/h)。断面积应按实测内径计算，圆形烟道 F = πD2/4。
崂应3012H-D说明书式(5)；Qs单位 m³/h

标干烟气流量（崂应式6）

计算公式（崂应 3012H-D 式6 · 标干烟气流量，GB/T 16157-1996）
Qsnd = Qs × 273/(273 + ts) × (Ba + Ps)/101.325 × (1 − Xsw)
Qs 工况湿烟气流量(m³/h)；Ba、Ps 单位为 kPa；Xsw 以百分数(%)输入，程序内部按 (1 − Xsw/100) 计算。标干流量是核算污染物排放速率与排放量的基准流量。
崂应3012H-D说明书式(6)；Xsw以%输入按(1−Xsw/100)计
4流速与工况参数（HJ1405）

烟气流速（皮托管 崂应式11）

计算公式（崂应 3012H-D 式11 · 皮托管法烟气流速，GB/T 16157-1996）
Vs = Kp × √( 2 Pd / ρ ) = 1.414 × Kp × √( Pd / ρ )
Kp 为皮托管系数（S 型约 0.84，标准型约 1.00，以校正证书为准）；Pd 为动压(Pa)；ρ 为工况烟气密度(kg/m³)。断面平均流速应先对各测点的 √Pd 求算术平均，再代入本式计算，不可先平均 Pd。
崂应3012H-D说明书式(11)；ρ可由"烟气密度"计算器求得

烟气密度（崂应式12）

计算公式（崂应 3012H-D 式12 · 工况烟气密度）
ρ = 1.34 × (Ba + Ps)/101.325 × 273/(273 + ts)
1.34 kg/m³ 为标准状态下一般燃烧烟气的近似密度。当烟气组分与空气差异较大（如高 CO2、高湿或含大量惰性气体）时，应先按实测组分计算标况密度 ρn 再代入。Ba、Ps 单位为 kPa。
崂应3012H-D说明书式(12)；1.34 为烟气密度系数(kg/m³, 标准状态)

静压计算（崂应式8）

计算公式（崂应 3012H-D 式8 · 烟道静压）
Ps = Pt − Kp × Pd / 1000
Pt 为全压(kPa)，Pd 为动压(Pa)，除以 1000 换算为 kPa 后相减。Ps 为负值表示烟道内处于负压状态（引风机在测点下游），此时标况换算中的 (Ba + Ps) 将小于大气压。
崂应3012H-D说明书式(8)；Ps单位 kPa

等速采样流量/采样嘴直径

计算公式（崂应式9/10 · 等速采样流量与采样嘴直径，GB/T 16157-1996）
等速采样流量：Qrs = 0.047 × Vs × d2 × (1 − Xsw)
采样嘴直径（由上式反解）：d = √[ Qrs / ( 0.047 × Vs × (1 − Xsw) ) ]
Vs 烟气流速(m/s)、d 采样嘴内径(mm)、Qrs 流量计前干气体流量(L/min)、Xsw 以百分数(%)输入。等速采样相对偏差应控制在 ±10% 以内。待确认：本卡“求采样嘴直径”分支当前使用 d = 0.047 × √[Qrs/(Vs(1−Xsw))]，与上式反解相差约 98 倍，请确认应采用哪一形式（涉及 JS 计算逻辑，本次未改动）。
崂应3012H-D说明书式(9)/(10)；Xsw以%输入按(1−Xsw/100)计

流速均方差（HJ1405）

计算公式（断面流速均方差与变异系数 · HJ 1405）
V̄ = (1/n) ∑ Vi
均方差（样本标准偏差） s = √[ ∑(Vi − V̄)2 / (n − 1) ]
变异系数 CV = s / V̄ × 100%   判据：CV ≤ 10%
用于评价烟道测定断面的流速分布均匀性。CV > 10% 表明流场不稳定或存在涡流，应增加测点数、延长直管段或另选监测断面，否则等速采样与流量核算结果代表性不足。
输入多次流速测定值，用逗号分隔
示例：13.5,14.2,12.8,13.9,14.0
参考 HJ 1405；s 为流速样本标准差(均方差)，CV 为变异系数(均匀度评估)

排放速率计算

计算公式（污染物排放速率 · GB/T 16157-1996 / GB 16297-1996）
G = C × Qsnd × 10−6  (kg/h)
C 为标态干基排放浓度(mg/m³)，Qsnd 为标态干烟气流量(m³/h)，10−6 为 mg → kg 的换算系数。所得排放速率须与 GB 16297-1996 表2（或行业排放标准）中按排气筒高度确定的最高允许排放速率比较后判定达标情况。
参考标准：HJ/T 397-2007；GB/T 16157-1996

实测烟尘浓度（崂应式7）

计算公式（崂应 3012H-D 式7 · 实测烟尘浓度，GB/T 16157-1996）
C = ( g2 − g1 ) × 106 / Vnd
g1、g2 分别为采样前、后滤筒（含捕集颗粒物）的质量，单位 g；Vnd 为标况采样体积，单位 L；106 为 g/L → mg/m³ 的换算系数，结果单位 mg/m³。低浓度颗粒物测定应按 HJ 836 执行恒重程序并作全程序空白滤膜修正。
崂应3012H-D说明书式(7)；C 单位 mg/m³

烟尘排放量（崂应式14）

计算公式（崂应 3012H-D 式14 · 烟尘排放量）
G = C × Qsnd × 10−6  (kg/h)
C 为实测烟尘浓度(mg/m³)，Qsnd 为标干烟气流量(m³/h)。核算时段排放总量按 W = G × T（T 为该工况实际运行小时数）累加；若有多个工况，应分别核算后求和。
崂应3012H-D说明书式(14)；G 单位 kg/h
5浓度 ↔ 体积分数换算（mg/m³ ↔ ppm ↔ %）

浓度 ↔ 体积分数换算

换算公式（质量浓度 ↔ 体积分数 · 理想气体状态方程）
ppm = C(mg/m³) × Vm × (273.15 + t)/Tref × 101.325/P ÷ M
C(mg/m³) = ppm × M ÷ [ Vm × (273.15 + t)/Tref × 101.325/P ]
vol% = ppm / 10000
Vm：标准状态 = 22.414 L/mol（Tref=273.15 K）；参比状态 = 24.465 L/mol（Tref=298.15 K，常取 24.5）
M 为摩尔质量(g/mol)，t 为温度(℃)，P 为大气压(kPa)。22.414 L/mol 是标准状态(0℃,101.325kPa)下的气体摩尔体积；24.465 L/mol（常取 24.5）是参比状态(25℃,101.325kPa)下的气体摩尔体积，二者均来自理想气体状态方程 RT/P，仅温度基准不同，都不是万能常数：计算时按所选"状态基准"取用对应 Vm 与 Tref，并保留 (273.15+t)/Tref × 101.325/P 温压修正因子（t=0、P=101.325 时化简）。注意：污染物排放标准中的 mg/m³ 通常指标准状态干基浓度，换算前应先完成状态与干基折算。
适用 SO₂、NO₂、NO、H₂S、CH₄、NH₃、CO、CO₂、O₂ 等；标准状态(0℃,101.325kPa)摩尔体积 22.414 L/mol，参比状态(25℃,101.325kPa)摩尔体积 24.465 L/mol（常取 24.5）；按所选"状态基准"取用，并保留温压修正。
6仪器校准（绝对误差 / 示值误差）

气体浓度校准（绝对/示值误差）

计算公式（气体分析仪示值误差 · HJ 57 / HJ 693 / GB/T 16157）
绝对误差 Δ = X测 − X标
示值误差（相对标准值）= (X测 − X标) / X标 × 100%
单位换算：C(μmol/mol) = C(mg/m³) × 22.4 / M
判定（HJ 57 / HJ 693）：
  C标 ≥ 100 μmol/mol → 允差 ≤ ±5%（相对标准值）
  C标 < 100 μmol/mol → 允差 ≤ ±5 μmol/mol（绝对）
M 为污染物气体分子量；22.4 为标准状态（0℃、101.325 kPa）摩尔体积 L/mol。标准气体浓度 ≥ 100 μmol/mol 时按相对标准值 ±5% 判定；< 100 μmol/mol 时按绝对误差 ±5 μmol/mol 判定（依据 HJ 57、HJ 693 示值误差性能要求，不再统一执行 ±5%）。
参考 HJ 57(SO₂)、HJ 693(NOx)；示值误差按标准气体浓度分段判定：≥100 μmol/mol ≤±5%，<100 μmol/mol ≤±5 μmol/mol

压力传感器示值误差（崂应式1）

计算公式（崂应 3012H-D 式1 · 压力示值误差）
ΔP = (P1 − P0) − Ps
P1 为仪器显示压力，P0 为当前实际大气压，二者之差即仪器指示的表压；Ps 为标准压力源给出的标准表压值。按仪器说明书，压力/大气压传感器标定允差取 ±0.5 kPa，|ΔP| 超出即判不合格，应重新标定。各量单位统一为 kPa。
崂应3012H-D说明书式(1)；大气压标定允差 ≤±0.5 kPa
厂界气象：依据 HJ/T 55-2000 进行无组织排放监测前/采样中气象参数判定，含矢量平均、太阳高度角、Pasquill 稳定度。
厂界无组织排放监测气象参数判定 · 依据 HJ/T 55-2007《大气污染物无组织排放监测技术导则》。

十次风向风速（监测前）

计算公式（HJ/T 55-2000 · 风向向量平均法）
u = −(1/n) ∑ sinθi   v = −(1/n) ∑ cosθi
平均风向 θ̄ = arctan2(u, v) (换算至 0°~360°)
平均风速 ū = (1/n) ∑ ui
合成向量长度 R = √(u2 + v2)
风向标准差 σθ = √(−2 ln R) × 180/π
HJ/T 55-2000 要求无组织排放监测前，在参照点连续观测 10 次风向、风速，据此确定主导风向并在下风向布设监控点。σθ 越小说明风向越稳定；因风向为角度量，必须用向量法而非算术平均。
HJ/T 55-2007 5.1.2：监测前每1 min读一次风向风速，共10次

五次风向风速（采样中）

计算公式（HJ/T 55-2000 · 采样过程风向向量平均）
u = −(1/n) ∑ sinθi   v = −(1/n) ∑ cosθi
平均风向 θ̄ = arctan2(u, v) (换算至 0°~360°)
平均风速 ū = (1/n) ∑ ui
风向标准差 σθ = √(−2 ln R)  R = √(u2 + v2)
采样过程中每隔一定时间观测 1 次、共 5 次风向风速，用于核实采样期间风向是否发生明显偏转。若采样期间平均风向与监测前主导风向偏差过大，监控点已偏离下风向，该组数据应作废重测。
HJ/T 55-2007 5.1.3：采样时每5 min读一次风向风速，共5次

太阳高度角与日期序数

计算公式（太阳赤纬与太阳高度角 · HJ/T 55-2000 / HJ 2.2 附录A）
太阳赤纬 δ = arcsin[ 0.39795 × cos(0.98563° × (n − 173)) ]
时角 ω = 15° × (t − 12)
sin h0 = sinφ · sinδ + cosφ · cosδ · cosω
太阳高度角 h0 = arcsin(sin h0)
n 为日期序数（1 月 1 日记为 1，闰年至 366）；φ 为测点纬度（北纬为正）；t 为真太阳时(h)。若使用北京时间，需先按 HJ 2.2 附录A 作经度修正：t真 ≈ t北京 + (λ − 120°)/15。h0 为负值表示太阳位于地平线以下（夜间）。
HJ/T 55-2007 附录A；用于大气稳定度判定的太阳高度角

大气稳定度判定（Pasquill）

判定方法（Pasquill 大气稳定度 · HJ/T 55-2000 / GB/T 13201 附录A）
第一步 · 太阳辐射等级
  昼间：h0 ≥ 60° 且总云量 N ≤ 2 → 强辐射
  昼间：h0 ≥ 35° 且总云量 N ≤ 4 → 中辐射
  昼间其余情形 → 弱辐射
  夜间：低云量 ≥ 4 为“云多”，< 4 为“云少”
第二步 · 以地面风速 u 交叉查表定级

K 为电导池常数(cm−1)，R 为实测电阻(Ω)。K/R 的单位为 S/cm，乘 106 换算为 μS/cm。电导池常数须用已知电导率的标准 KCl 溶液定期标定，电极污染或老化会使 K 发生漂移。
电极法水质检测：κ = K/R

电导率温度补偿

计算公式（电导率温度补偿至 25 ℃）
κ25 = κt / [ 1 + α (t − 25) ]
α 为温度系数，一般天然水样取 0.02 /℃（即 2%/℃）；强酸、强碱及高盐溶液应实测确定 α。报出电导率结果时须统一折算到 25 ℃基准，并注明是否已作温度补偿。
电导率基准温度补偿（常用线性补偿）

pH电极斜率温度补偿

计算公式（Nernst 方程理论斜率）
ST = 0.05916 × (T + 273.15) / 298.15  (V/pH)
ST = 59.16 × (T + 273.15) / 298.15  (mV/pH)
25 ℃ 时理论斜率为 59.16 mV/pH，温度每升高 10 ℃ 约增大 2 mV/pH。电极实用斜率与理论斜率之比（电极效率）应在 95%~105% 之间，低于 95% 说明电极钝化，需活化或更换。
玻璃电极理论斜率随温度变化（Nernst方程）

电位(mV)→pH换算

计算公式（电位 → pH 换算 · Nernst 方程）
pH = pHiso + ( Eiso − E ) / S
自动斜率 S = 59.16 × (T + 273.15) / 298.15  (mV/pH)
电极效率 = S实用 / S理论 × 100%，合格区间 95% ~ 105%
pHiso 与 Eiso 为定位（等电位）点的 pH 与电位，通常以 pH 6.86 缓冲液定位，理想电极此点电位接近 0 mV。若计算 pH 超出 0~14 量程，应检查电位符号、定位点取值与电极状态。
GB/T 6920-1986 玻璃电极法：以pH7缓冲液定位，pH = pHiso + (Eiso − E)/S；斜率S按Nernst方程随温度变化，25℃为59.16 mV/pH。电极斜率应在理论值的95%~105%之间

水质浓度换算

换算公式（质量浓度 / 摩尔浓度 / 以元素计）
摩尔浓度 c(mmol/L) = ρ(mg/L) / M(g/mol)
以元素计 ρ元素 = ρ化合物 × f   f = M元素 / M化合物
常见换算因子：NO3− 以 N 计 f = 14/62 = 0.2259；NH4+ 以 N 计 f = 14/18 = 0.7778；SO42− 以 S 计 f = 32/96 = 0.3333；PO43− 以 P 计 f = 31/95 = 0.3263。程序已内置常见指标的 M 与 f，选择指标后自动换算。报出结果时必须注明计量基准（以 N 计 / 以化合物计）。
