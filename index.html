计算公式
C折 = C实测 × (21 − O2基准) / (21 − O2实测)

C折 = C实测 × α基准 / α实测 × K

非甲烷总烃 干基浓度（HJ1332）

计算公式（湿基 → 干基）
C干基 = C湿基 / (1 − Xsw)

油烟净化效率（GB18483）

计算公式（基于排放速率）
η = (C前Q前 − C后Q后) / (C前Q前) × 100%
参考标准：GB 18483-2001《饮食业油烟排放标准》；G前后=CQ (排放速率)

油烟基准风量折算浓度（GB 18483）

计算公式（GB 18483-2001 第 6.6 条）
c基 = c测 × Q测 / (n × q基)
c基：折算为单个灶头基准排风量时的排放浓度，mg/m³；Q测：实测排风量，m³/h；q基：单个灶头基准排风量，大/中/小型均为 2000 m³/h；n：折算的工作灶头个数。
参考标准：GB 18483-2001《饮食业油烟排放标准》第 6.6 条、表 2（小型/中型/大型餐饮单位油烟最高允许排放浓度均为 2.0 mg/m³，净化设施最低去除效率分别为 60%、75%、85%）。
2排放标准判定（GB16297 内插/外推）

排气筒高度 内插/外推法

计算公式（GB 16297-1996 附录B · 排气筒最高允许排放速率内插/外推）
内插法（表列 ha < h < ha+1）：
  Q = Qa + (Qa+1 − Qa) / (ha+1 − ha) × (h − ha)
外推法（h > 表列最高值 hb）：
  Q = Qb × ( h / hb )2
达标判定：实测排放速率 G ≤ Q
排气筒高度低于 15 m 时，其最高允许排放速率按外推结果再严格 50%（即取 Q/2）执行。两个排气筒之间距离小于该两个排气筒高度之和时，应合并视为一个等效排气筒计算。
参考标准：GB 16297-1996 附录B；外推结果对新源高度<15m 时再严格50%

等效排气筒(GB 16297 附录A)

计算公式（等效排气筒 · GB 16297-1996 附录A）
等效排放速率 Q = Q₁ + Q₂
等效排气筒高度 h = √[(h₁² + h₂²)/2]
位置 x = a·Q₂/Q（距排气筒1，沿连线）
当两排气筒排放同种污染物且间距 a < (h₁+h₂) 时，须合并为一根等效排气筒；三根以上依序与等效排气筒再取等效。Q 为排放速率(kg/h)，h 为排气筒高度(m)，a 为两筒间距(m)。
参考标准：GB 16297-1996《大气污染物综合排放标准》附录A（等效排气筒参数计算）
3体积与流量换算（GB16157/GB3095）

标态干烟气流量换算

计算公式（标态干烟气流量 · GB/T 16157-1996）
Qsnd = Qs × 273/(273 + ts) × (Pa + Ps)/101325 × (1 − Xsw)
Qs 工况湿烟气流量(m³/h)；ts 烟气温度(℃)；Pa 大气压、Ps 烟道静压，本卡两者均以 Pa 为单位（故分母取 101325 Pa）；Xsw 为烟气含湿量体积分数，以小数 0~1 输入。标准状态指 273 K、101325 Pa 的干烟气状态。
参考标准：HJ/T 397-2007；GB/T 16157-1996；Xsw为小数体积分数

体积换算（标况/参比）

计算公式（体积状态换算 · GB/T 16157-1996 / HJ 194-2017 / HJ/T 55-2000）
废气标况（干基）：Vnd = V × 273/(273 + t) × (Ba + Ps)/101.325 × (1 − Xsw)
环境空气参比状态：Vr = V × 298.15/(273.15 + t) × P/101.325
无组织排放标况：Vs = V × 273/(273 + t) × Ba/101.325 × (1 − Xsw)
压力单位统一为 kPa，Xsw 以百分数(%)输入。废气标准状态为 273 K、101.325 kPa；环境空气按 HJ 194-2017 采用 298.15 K、101.325 kPa 参比状态。无组织采样点位于敞开大气中，不叠加烟道静压 Ps。
废气/无组织:0℃·101.325kPa干基;环境空气参比:25℃·101.325kPa(GB3095附录A)

标况采样体积（崂应式4）

计算公式（崂应 3012H-D 式4 · 标况采样体积，GB/T 16157-1996）
Vnd = V × 273/(273 + ts) × (Ba + Ps)/101.325
V 为累积流量计示值给出的实际采样体积(L)；ts 为流量计前气体温度(℃)；Ba 为大气压、Ps 为流量计前表压，单位均为 kPa。结果为 273 K、101.325 kPa 下的标况体积(L)，用于计算颗粒物与气态污染物浓度。
崂应3012H-D说明书式(4)；Ba、Ps单位 kPa，标准 101.325 kPa

烟气工况流量（崂应式5）

计算公式（崂应 3012H-D 式5 · 工况烟气流量，GB/T 16157-1996）
Qs = 3600 × Vs × F
Vs 为烟道测定断面的平均流速(m/s)，F 为烟道断面积(m²)，系数 3600 为 s→h 换算，结果为工况湿烟气流量(m³/h)。断面积应按实测内径计算，圆形烟道 F = πD2/4。
崂应3012H-D说明书式(5)；Qs单位 m³/h

标干烟气流量（崂应式6）

计算公式（崂应 3012H-D 式6 · 标干烟气流量，GB/T 16157-1996）
Qsnd = Qs × 273/(273 + ts) × (Ba + Ps)/101.325 × (1 − Xsw)
Qs 工况湿烟气流量(m³/h)；Ba、Ps 单位为 kPa；Xsw 以百分数(%)输入，程序内部按 (1 − Xsw/100) 计算。标干流量是核算污染物排放速率与排放量的基准流量。
崂应3012H-D说明书式(6)；Xsw以%输入按(1−Xsw/100)计
4流速与工况参数（HJ1405）

烟气流速（皮托管 崂应式11）

计算公式（崂应 3012H-D 式11 · 皮托管法烟气流速，GB/T 16157-1996）
Vs = Kp × √( 2 Pd / ρ ) = 1.414 × Kp × √( Pd / ρ )
Kp 为皮托管系数（S 型约 0.84，标准型约 1.00，以校正证书为准）；Pd 为动压(Pa)；ρ 为工况烟气密度(kg/m³)。断面平均流速应先对各测点的 √Pd 求算术平均，再代入本式计算，不可先平均 Pd。
崂应3012H-D说明书式(11)；ρ可由"烟气密度"计算器求得

烟气密度（崂应式12）

计算公式（崂应 3012H-D 式12 · 工况烟气密度）
ρ = 1.34 × (Ba + Ps)/101.325 × 273/(273 + ts)
1.34 kg/m³ 为标准状态下一般燃烧烟气的近似密度。当烟气组分与空气差异较大（如高 CO2、高湿或含大量惰性气体）时，应先按实测组分计算标况密度 ρn 再代入。Ba、Ps 单位为 kPa。
崂应3012H-D说明书式(12)；1.34 为烟气密度系数(kg/m³, 标准状态)

静压计算（崂应式8）

计算公式（崂应 3012H-D 式8 · 烟道静压）
Ps = Pt − Kp × Pd / 1000
Pt 为全压(kPa)，Pd 为动压(Pa)，除以 1000 换算为 kPa 后相减。Ps 为负值表示烟道内处于负压状态（引风机在测点下游），此时标况换算中的 (Ba + Ps) 将小于大气压。
崂应3012H-D说明书式(8)；Ps单位 kPa

等速采样流量/采样嘴直径

计算公式（崂应式9/10 · 等速采样流量与采样嘴直径，GB/T 16157-1996）
等速采样流量：Qrs = 0.047 × Vs × d2 × (1 − Xsw)
采样嘴直径（由上式反解）：d = √[ Qrs / ( 0.047 × Vs × (1 − Xsw) ) ]
Vs 烟气流速(m/s)、d 采样嘴内径(mm)、Qrs 流量计前干气体流量(L/min)、Xsw 以百分数(%)输入。等速采样相对偏差应控制在 ±10% 以内。待确认：本卡“求采样嘴直径”分支当前使用 d = 0.047 × √[Qrs/(Vs(1−Xsw))]，与上式反解相差约 98 倍，请确认应采用哪一形式（涉及 JS 计算逻辑，本次未改动）。
崂应3012H-D说明书式(9)/(10)；Xsw以%输入按(1−Xsw/100)计

流速均方差（HJ 1405-2024）

计算公式（流速相对均方差 σr 与变异系数 · HJ 1405-2024 §4.2.4）
平均流速 v̄ = (1/n) ∑ vi
绝对标准差 s = √[ ∑(vi − v̄)2 / (n − 1) ]
流速相对均方差 σr = s / v̄ = √[ ∑(vi − v̄)2 / ((n − 1) × v̄2) ]
变异系数 CV = s / v̄ × 100%   判据：σr ≤ 0.15（HJ 1405-2024 §4.2.4）
用于评价烟道测定断面的流速分布均匀性。HJ 1405-2024 §4.2.4 以"流速相对均方差 σr"（无量纲）判定：σr > 0.15 表明流场不稳定或存在涡流，应增加测点数、延长直管段或另选监测断面，否则等速采样与流量核算结果代表性不足。σr = s / v̄ = CV / 100。注：HJ 1405-2024 自 2027-01-01 实施，过渡期内 GB/T 16157、HJ/T 397 关于采样位置与测点的要求仍适用。
输入多次流速测定值，用逗号分隔
示例：13.5,14.2,12.8,13.9,14.0
参考 HJ 1405-2024 §4.2.4：σr 为流速相对均方差(无量纲)，s 为绝对标准差，CV 为变异系数(均匀度评估)

排放速率计算

计算公式（污染物排放速率 · GB/T 16157-1996 / GB 16297-1996）
G = C × Qsnd × 10−6  (kg/h)
C 为标态干基排放浓度(mg/m³)，Qsnd 为标态干烟气流量(m³/h)，10−6 为 mg → kg 的换算系数。所得排放速率须与 GB 16297-1996 表2（或行业排放标准）中按排气筒高度确定的最高允许排放速率比较后判定达标情况。
参考标准：HJ/T 397-2007；GB/T 16157-1996

实测烟尘浓度（崂应式7）

计算公式（崂应 3012H-D 式7 · 实测烟尘浓度，GB/T 16157-1996）
C = ( g2 − g1 ) × 106 / Vnd
g1、g2 分别为采样前、后滤筒（含捕集颗粒物）的质量，单位 g；Vnd 为标况采样体积，单位 L；106 为 g/L → mg/m³ 的换算系数，结果单位 mg/m³。低浓度颗粒物测定应按 HJ 836-2017 执行恒重程序并作全程序空白滤膜修正。
崂应3012H-D说明书式(7)；C 单位 mg/m³

烟尘排放量（崂应式14）

计算公式（崂应 3012H-D 式14 · 烟尘排放量）
G = C × Qsnd × 10−6  (kg/h)
C 为实测烟尘浓度(mg/m³)，Qsnd 为标干烟气流量(m³/h)。核算时段排放总量按 W = G × T（T 为该工况实际运行小时数）累加；若有多个工况，应分别核算后求和。
崂应3012H-D说明书式(14)；G 单位 kg/h
5浓度 ↔ 体积分数换算（mg/m³ ↔ ppm ↔ %）

浓度 ↔ 体积分数换算

换算公式（质量浓度 ↔ 体积分数 · 理想气体状态方程）
ppm = C(mg/m³) × Vm × (273.15 + t)/Tref × 101.325/P ÷ M
C(mg/m³) = ppm × M ÷ [ Vm × (273.15 + t)/Tref × 101.325/P ]
vol% = ppm / 10000
Vm：标准状态 = 22.414 L/mol（Tref=273.15 K）；参比状态 = 24.465 L/mol（Tref=298.15 K，常取 24.5）
M 为摩尔质量(g/mol)，t 为温度(℃)，P 为大气压(kPa)。22.414 L/mol 是标准状态(0℃,101.325kPa)下的气体摩尔体积；24.465 L/mol（常取 24.5）是参比状态(25℃,101.325kPa)下的气体摩尔体积，二者均来自理想气体状态方程 RT/P，仅温度基准不同，都不是万能常数：计算时按所选"状态基准"取用对应 Vm 与 Tref，并保留 (273.15+t)/Tref × 101.325/P 温压修正因子（t=0、P=101.325 时化简）。注意：污染物排放标准中的 mg/m³ 通常指标准状态干基浓度，换算前应先完成状态与干基折算。
适用 SO₂、NO₂、NO、H₂S、CH₄、NH₃、CO、CO₂、O₂ 等；标准状态(0℃,101.325kPa)摩尔体积 22.414 L/mol，参比状态(25℃,101.325kPa)摩尔体积 24.465 L/mol（常取 24.5）；按所选"状态基准"取用，并保留温压修正。
6仪器校准（绝对误差 / 示值误差）

气体浓度校准（绝对/示值误差）

计算公式（气体分析仪示值误差 · HJ 57 / HJ 693 / GB/T 16157）
绝对误差 Δ = X测 − X标
示值误差（相对标准值）= (X测 − X标) / X标 × 100%
单位换算：C(μmol/mol) = C(mg/m³) × 22.4 / M
判定（HJ 57 / HJ 693）：
  C标 ≥ 100 μmol/mol → 允差 ≤ ±5%（相对标准值）
  C标 < 100 μmol/mol → 允差 ≤ ±5 μmol/mol（绝对）
M 为污染物气体分子量；22.4 为标准状态（0℃、101.325 kPa）摩尔体积 L/mol。标准气体浓度 ≥ 100 μmol/mol 时按相对标准值 ±5% 判定；< 100 μmol/mol 时按绝对误差 ±5 μmol/mol 判定（依据 HJ 57、HJ 693 示值误差性能要求，不再统一执行 ±5%）。
参考 HJ 57(SO₂)、HJ 693(NOx)；示值误差按标准气体浓度分段判定：≥100 μmol/mol ≤±5%，<100 μmol/mol ≤±5 μmol/mol

压力传感器示值误差（崂应式1）

计算公式（崂应 3012H-D 式1 · 压力示值误差）
ΔP = (P1 − P0) − Ps
P1 为仪器显示压力，P0 为当前实际大气压，二者之差即仪器指示的表压；Ps 为标准压力源给出的标准表压值。按仪器说明书，压力/大气压传感器标定允差取 ±0.5 kPa，|ΔP| 超出即判不合格，应重新标定。各量单位统一为 kPa。
崂应3012H-D说明书式(1)；大气压标定允差 ≤±0.5 kPa
厂界气象：依据 HJ/T 55-2000 进行无组织排放监测前/采样中气象参数判定，含矢量平均、太阳高度角、Pasquill 稳定度。
厂界无组织排放监测气象参数判定 · 依据 HJ/T 55-2000《大气污染物无组织排放监测技术导则》。

十次风向风速（监测前）

计算公式（HJ/T 55-2000 · 风向向量平均法）
u = −(1/n) ∑ sinθi   v = −(1/n) ∑ cosθi
平均风向 θ̄ = arctan2(u, v) (换算至 0°~360°)
平均风速 ū = (1/n) ∑ ui
合成向量长度 R = √(u2 + v2)
风向标准差 σθ = √(−2 ln R) × 180/π
HJ/T 55-2000 要求无组织排放监测前，在参照点连续观测 10 次风向、风速，据此确定主导风向并在下风向布设监控点。σθ 越小说明风向越稳定；因风向为角度量，必须用向量法而非算术平均。
HJ/T 55-2000 5.1.2：监测前每1 min读一次风向风速，共10次

五次风向风速（采样中）

计算公式（HJ/T 55-2000 · 采样过程风向向量平均）
u = −(1/n) ∑ sinθi   v = −(1/n) ∑ cosθi
平均风向 θ̄ = arctan2(u, v) (换算至 0°~360°)
平均风速 ū = (1/n) ∑ ui

太阳高度角与日期序数

计算公式（太阳赤纬与太阳高度角 · HJ/T 55-2000 / HJ 2.2-2018 附录A）
太阳赤纬 δ = arcsin[ 0.39795 × cos(0.98563° × (n − 173)) ]
时角 ω = 15° × (t − 12)
sin h0 = sinφ · sinδ + cosφ · cosδ · cosω

n 为日期序数（1 月 1 日记为 1，闰年至 366）；φ 为测点纬度（北纬为正）；t 为真太阳时(h)。若使用北京时间，需先按 HJ 2.2-2018 附录A 作经度修正：t真 ≈ t北京 + (λ − 120°)/15。h0 为负值表示太阳位于地平线以下（夜间）。

大气稳定度判定（Pasquill）

背景(本底)噪声修正

计算公式（背景噪声修正 · HJ 706-2014 / GB 12348-2008 附录A）
ΔL = L总 − L背
ΔL < 3 dB → 测量无效，须降低背景噪声后重测
3 dB ≤ ΔL < 10 dB → L = 10 lg( 100.1L总 − 100.1L背 )
ΔL ≥ 10 dB → 修正量 < 0.5 dB，取 L = L总
L总 为声源与背景同时存在时的测量值，L背 为声源停止运行后的本底值，两者测点、档位、时长应完全一致。修正结果按标准要求取整到个位。
HJ 706-2014 / GB 12348：ΔL=L总−L背。ΔL≥10 dB 时修正量<0.5 dB，不修正；3 dB≤ΔL<10 dB 时按能量相减 L=10lg(10^0.1L总−10^0.1L背)；ΔL<3 dB 时测量无效，应待背景降低后重测或采取措施后再测

因 1 m³ = 1000 L，故 m³/h × mg/L × h 的乘积单位恰为 g，无需额外换算系数。排污许可执行报告中的时段排放量应按各时段实际废水量与浓度的加权结果分段累加，不能用瞬时流量简单外推。

阻值换算(电导率)

计算公式（电阻 → 电导率换算）
κ = K / R × 106  (μS/cm)
K 为电导池常数(cm−1)，R 为实测电阻(Ω)。K/R 的单位为 S/cm，乘 106 换算为 μS/cm。电导池常数须用已知电导率的标准 KCl 溶液定期标定，电极污染或老化会使 K 发生漂移。

电导率温度补偿

计算公式（电导率温度补偿至 25 ℃）
κ25 = κt / [ 1 + α (t − 25) ]
α 为温度系数，一般天然水样取 0.02 /℃（即 2%/℃）；强酸、强碱及高盐溶液应实测确定 α。报出电导率结果时须统一折算到 25 ℃基准，并注明是否已作温度补偿。

计算公式（Nernst 方程理论斜率）
ST = 0.05916 × (T + 273.15) / 298.15  (V/pH)
ST = 59.16 × (T + 273.15) / 298.15  (mV/pH)
25 ℃ 时理论斜率为 59.16 mV/pH，温度每升高 10 ℃ 约增大 2 mV/pH。电极实用斜率与理论斜率之比（电极效率）应在 95%~105% 之间，低于 95% 说明电极钝化，需活化或更换。

计算公式（电位 → pH 换算 · Nernst 方程）
pH = pHiso + ( Eiso − E ) / S
自动斜率 S = 59.16 × (T + 273.15) / 298.15  (mV/pH)
电极效率 = S实用 / S理论 × 100%，合格区间 95% ~ 105%

风口法：Q 为总新风量(m³/h)=各送风口风量 q(m³/h)之和/测点数 n。示踪气体法：V 为房间体积(m³)，C₀/C_t 为初始/末态浓度，t 为时间(h)。人均新风量=Q/人数。
参考标准：GB/T 18204.1-2025《公共场所卫生检验方法 第1部分：物理性指标》

换气次数

计算公式（GB/T 18204.1-2025）
N(次/h) = Q / V
Q 为房间总通风量(m³/h)，V 为房间体积(m³)。不同类型公共场所换气次数限值见 GB 37487-2019 / GB 37488-2019（如影剧院、商场等）。
参考标准：GB/T 18204.1-2025《公共场所卫生检验方法 第1部分：物理性指标》
5公共用品用具

用品用具细菌总数（CFU/25cm²）

计算公式（GB/T 18204.4-2025）
细菌总数(CFU/25cm²) = 平皿菌落数 × 25 / 采样面积(cm²)
以 5 cm × 5 cm 规格板采样时，采样面积为 25 cm²，结果即等于平皿菌落数。若使用不同规格采样框，按实际采样面积换算。
参考标准：GB/T 18204.4-2025《公共场所卫生检验方法 第4部分：公共用品用具微生物指标》

用品微生物通用计算

计算公式（GB/T 18204.4-2025 / GB 15979-2024）
细菌总数 = 平皿菌落数 × 稀释倍数 / 采样面积
大肠菌群(MPN) = MPN 表查值 × 稀释倍数 / 采样面积
细菌总数以 CFU/cm² 或 CFU/25cm² 报出；致病菌定性（检出/未检出）不计算浓度。采样面积按实际规格板（通常 25 cm²）代入。一次性卫生用品参照 GB 15979-2024。
参考标准：GB/T 18204.4-2025；GB 15979-2024《一次性使用卫生用品卫生要求》
6集中空调通风系统

风管内表面积尘量

计算公式（称重法 · GB/T 18204.5-2025）
积尘量(g/m²) = (m − m₀) / (L × W)
（m₀ 滤膜/称量瓶质量，m 采样后总质量，L、W 为采样框长宽）
采样框常用 10 cm × 10 cm（0.01 m²）或 5 cm × 5 cm（0.0025 m²）。结果以风管内表面积尘量 g/m² 报出。
参考标准：GB/T 18204.5-2025《公共场所卫生检验方法 第5部分：集中空调通风系统》

空调风管内/送风口微生物

计算公式（GB/T 18204.5-2025）
细菌总数 = 平皿菌落数 × 1000 / (Q × t)　CFU/m³
撞击法：Q 为采样流量(L/min)，t 为采样时间(min)。送风口/风管内表面菌落以 CFU/cm² 报出（按采样面积换算）。β-溶血性链球菌、嗜肺军团菌为定性。
参考标准：GB/T 18204.5-2025《公共场所卫生检验方法 第5部分：集中空调通风系统》

可吸入颗粒物（PM10）

计算公式（重量法 · GB/T 18204.5-2025 / HJ 618）
ρ(mg/m³) = (m − m₀) × 1000 / Vnd
m₀ 为空白滤膜质量，m 为采样后滤膜质量，Vₙ𝒹 为标况采气体积（L）。结果以 mg/m³ 报出。集中空调送风中 PM10 限值见 WS 10013-2023 / GB 37488。
参考标准：GB/T 18204.5-2025；HJ 618-2011《环境空气 PM10和PM2.5的测定 重量法》
7洁净室

悬浮粒子浓度换算

计算公式（GB 50591-2010 / GB/T 16292-2025）
Cn = 采样点粒子总数 / 采样气体体积
换算为每立方米：C = 计数 × 1000 / V采样(L)
洁净室悬浮粒子以粒/m³ 报出。采样体积 = 采样流量（L/min）× 采样时间（min）。采样点布置、最小采样量及粒子计数器要求按 GB 50591-2010 附录 E。
参考标准：GB 50591-2010《洁净室施工及验收规范》；GB/T 16292-2025《医药工业洁净室（区）悬浮粒子的测试方法》（2026-11-01 起实施新版）

风速不均匀度

计算公式（GB 50591-2010 附录 C）
β = (1 − v̄²/Σvᵢ²)^½ ×100%　或　β = (σ/ v̄)×100%
v̄ 为各测点风速平均值，vᵢ 为各测点风速，σ 为标准差。适用于单向流洁净室风口或截面的风速均匀性判定。
参考标准：GB 50591-2010《洁净室施工及验收规范》

自净时间

计算公式（GB 50591-2010 附录 D）
t = (N₀/N − 1) × (V/Q)　或　N/N₀ = e^(−n·t)
N₀ 为污染浓度初值，N 为目标浓度（通常取自净至 0.01 N₀），V 为室体积，Q 为换气量，n 为换气次数。实测时用气溶胶衰减法。
参考标准：GB 50591-2010《洁净室施工及验收规范》

换气次数（洁净室）

计算公式（GB 50591-2010 / GB 50073-2013）
n(次/h) = L / V
L 为洁净室总送风量(m³/h)，V 为房间体积(m³)。非单向流洁净室换气次数按级别定（如 10 万级≥15 次/h，1 万级≥25 次/h）。
参考标准：GB 50591-2010；GB 50073-2013《洁净厂房设计规范》

漏风率（围护结构）

计算公式（GB 50591-2010）
漏风率 = (q₁ − q₂) / q₁ × 100%　（q 为总送风量±压差时的风量差）
洁净室维持正压时漏风率应满足级别要求（如 1~10 万级≤1%~2%）。也可按 L漏 = q₁ − q₂ 直接求漏风量。
参考标准：GB 50591-2010《洁净室施工及验收规范》

静压差（相邻洁净区）

计算公式（GB 50591-2010 / GB 50073-2013）
ΔP = P_高 − P_低
不同级别洁净室之间静压差≥5 Pa，洁净室与非洁净室之间≥5 Pa，与室外≥10 Pa。本卡计算相邻区域实测压差。
参考标准：GB 50591-2010；GB 50073-2013

浮游菌浓度

计算公式（GB/T 16293-2025）
浮游菌(CFU/m³) = 菌落数 / (采样流量 Q × 采样时间 t) × 1000
Q 单位 L/min，t 单位 min，结果以 CFU/m³ 报出。单向流采样点布置按 GB/T 16293 附录。
参考标准：GB/T 16293-2025《医药工业洁净室（区）浮游菌的测试方法》（2026-11-01 起实施新版）

沉降菌浓度

计算公式（GB/T 16294-2025）
沉降菌(CFU/皿·h 或 CFU/m³) = 菌落数 / 暴露时间 T
T 为平皿暴露时间(h)。结果常以 CFU/皿·(0.5h) 报出，再按奥梅梁斯基公式换算 CFU/m³（近似）。本卡按 CFU/皿·h 计算。
参考标准：GB/T 16294-2025《医药工业洁净室（区）沉降菌的测试方法》（2026-11-01 起实施新版）

照度均匀度

计算公式（GB 50591-2010 / GB/T 50034-2024）
U = E_min / E_avg
E_min 为最低照度，E_avg 为平均照度。洁净室工作区照度均匀度一般不低于 0.7。本卡与 p9 同构，专为洁净室设入口。
参考标准：GB 50591-2010；GB/T 50034-2024《建筑照明设计标准》
8室内环境

甲醛浓度（酚试剂分光光度法）

计算公式（GB/T 18204.2-2025 / GB/T 18883-2022）
C(mg/m³) = (A − A₀) × Bs / Vnd
（Vnd 由本模块“标况采样体积换算 P1”给出：Vnd = V×(P/101.325)×273.15/(273.15+t)）
A、A₀ 分别为样品和空白吸光度；Bs 为计算因子（μg/吸光度），由标准曲线斜率倒数求得；Vnd 为标准状况下采样体积（L）。GB/T 18883-2022 限量 0.08 mg/m³（1h 均值）。
参考标准：GB/T 18204.2-2025《公共场所卫生检验方法 第2部分：化学性指标》；GB/T 18883-2022《室内空气质量标准》

苯/甲苯/二甲苯（TVOC组分）

计算公式（GC 外标法 · HJ 583-2010 / GB 50325）
C(mg/m³) = (A − A₀) × C标 / A标　（经 Tenax 富集热解吸）
A、A₀ 为样品、空白峰面积，C标 为标准物浓度，A标 为标准峰面积。兼顾 GB/T 18883（GB/T 18883-2022 限量 苯 0.03 mg/m³）。与 g1-gces 同构，此处用于室内空气入口。
参考标准：HJ 583-2010《环境空气 苯系物的测定 活性炭吸附/二硫化碳解吸-气相色谱法》；GB 50325-2020；GB/T 18883-2022

TVOC（总挥发性有机物）

计算公式（GC-MS 全扫描 · GB/T 18883-2022 / ISO 16000-6）
TVOC = ΣCᵢ（各定性组分浓度之和，甲苯当量）
以保留时间窗内各色谱峰对应的浓度（以甲苯响应因子换算）求和。结果以 mg/m³ 报出，GB/T 18883-2022 限量 0.60 mg/m³（8h 均值）。
参考标准：GB/T 18883-2022《室内空气质量标准》；ISO 16000-6

氡浓度（Rn-222）

计算公式（累积法/连续法 · GB/T 16146-2015 / GB 50325）
C(Bq/m³) = N / (E × t)　或　C = 仪器直接读数 / 校准因子
N 为探测片净计数（扣除本底），E 为探测器效率（cpm/(Bq/m³)），t 为暴露时间（h）；连续法由仪器直读。适用标准与限值：①工程验收 GB 50325-2020（强制性）：氡 ≤150 Bq/m³（Ⅰ/Ⅱ类统一，自然通风建筑关闭门窗 24h 后测）；②室内空气质量评价 GB/T 18883-2022（推荐性）：年平均值 ≤300 Bq/m³。注：GB 50325-2010 旧版曾为 Ⅰ类 200 / Ⅱ类 400 Bq/m³，2020 版已收严统一为 150。
参考标准：GB/T 16146-2015《室内氡及其子体控制要求》；GB 50325-2020；GB/T 18883-2022

二氧化碳 CO₂（计算/换算）

计算公式（GB/T 18204.2-2025 / GB/T 18883）
浓度通常为仪器直读；本卡提供 ppm→mg/m³ 换算
CO₂ 质量浓度 ρ(mg/m³) = C(ppm) × 1.977。GB/T 18883-2022 限量 0.10%（体积分数，≈1000 ppm，1h 平均）。
参考标准：GB/T 18204.2-2025；GB/T 18883-2022

PM2.5 / PM10 质量浓度

计算公式（重量法 · HJ 618 / GB/T 18883）
ρ(mg/m³) = (m − m₀) × 1000 / Vnd
m₀ 空白滤膜质量(mg)，m 采样后质量(mg)，Vₙ𝒹 标况采气体积(L)。GB/T 18883-2022 限量 PM2.5 24h平均 0.075 mg/m³、PM10 24h平均 0.15 mg/m³。
参考标准：HJ 618-2011；GB/T 18883-2022

氨（室内）

计算公式（GB/T 18204.2-2025 8.2 / GB 50325）
C(mg/m³) = (A − A₀) × Bs / Vnd
靛酚蓝分光光度法，Bₛ 为标准曲线斜率（μg/吸光度），Vₙ𝒹 标况采气体积(L)。GB 50325-2020 限量 Ⅰ类 0.15 mg/m³、Ⅱ类 0.20 mg/m³。
参考标准：GB/T 18204.2-2025；GB 50325-2020；GB/T 18883-2022
9学校

照度均匀度

计算公式（GB/T 5700-2023 / GB/T 18205-2012）
均匀度 U = Emin / Eavg
Eavg = ΣEi / n
在测量区域内按网格布点，测得各点照度 Ei。教室课桌面照度均匀度不应低于 0.7，黑板面不应低于 0.8（GB 7793-2025 / GB/T 18205-2012）。本卡输入逗号分隔照度值即可。GB 7793-2025 新增采光均匀度、蓝光危害 RG0、频闪 SVM 指标，2026-11-01 实施。
参考标准：GB/T 5700-2023《照明测量方法》；GB/T 18205-2012《学校卫生综合评价》；GB 7793-2025《中小学校教室采光和照明卫生标准》

教室窗地面积比

计算公式（GB 7793-2025 / GB/T 18205-2012）
窗地比 = 透光窗口面积 / 室内地面面积
中小学校教室窗地面积比不应低于 1:5（即 ≥0.20）。本卡计算比值并判定是否达标。
参考标准：GB 7793-2025《中小学校教室采光和照明卫生标准》；GB/T 18205-2012

采光系数

计算公式（GB/T 5699-2017 / GB 7793-2025）
C = (Ein / Eout) × 100%
E_in 为室内典型工作面照度，E_out 为室外全云天水平照度。教室采光系数最低值不应低于 2.0%（GB 7793-2025）。本卡按瞬时值计算。
参考标准：GB/T 5699-2017《采光测量方法》；GB 7793-2025

课桌面照度达标判定

计算公式（GB 7793-2025）
平均照度 E_avg = ΣEᵢ / n；判定 E_avg ≥ 300 lx 且 U ≥ 0.7
教室课桌面平均照度不低于 300 lx，照度均匀度不低于 0.7。本卡输入逗号分隔照度值，输出平均照度、均匀度及达标结论。
参考标准：GB 7793-2025《中小学校教室采光和照明卫生标准》
10一次性使用卫生用品

细菌菌落总数（GB 15979）

计算公式（GB 15979-2024）
N(CFU/g 或 CFU/mL) = ΣC / (n₁ + 0.1 n₂) × d × k
（典型：N = 平均菌落数 × 稀释倍数）
样品按标准方法稀释后倾注平板，计数 30~300 CFU 的平板。若两个连续稀释度均有计数，按 GB 15979-2024 第5章检验方法计数。一次性使用卫生用品普通级细菌菌落总数 ≤ 200 CFU/g（或 CFU/mL），消毒级 ≤ 20 CFU/g。
参考标准：GB 15979-2024《一次性使用卫生用品卫生要求》（含第5章检验方法）

大肠菌群（MPN）

计算公式（GB 15979-2024 检验方法）
大肠菌群(MPN/g 或 MPN/mL) = MPN 查表值 × 稀释倍数 / 取样量
采用 MPN 法（最可能数），根据阳性管数查 MPN 检索表得每 g(mL) 的 MPN 值。一次性用品普通级大肠菌群不得检出，消毒级不得检出。本卡输入查表 MPN 值与稀释倍数。
参考标准：GB 15979-2024（含第5章检验方法）

真菌菌落总数

计算公式（GB 15979-2024 检验方法）
真菌(CFU/g 或 CFU/mL) = 平均菌落数 × 稀释倍数 / 取样量
沙氏培养基倾注或涂布，计数真菌菌落。一次性用品普通级真菌菌落总数 ≤ 100 CFU/g，消毒级 ≤ 不得检出（按标准）。本卡按定量公式计算。
参考标准：GB 15979-2024（含第5章检验方法）

致病性化脓菌判定

判定规则（GB 15979-2024）
绿脓杆菌 / 金黄色葡萄球菌 / 溶血性链球菌：定性（检出 / 未检出）
致病性化脓菌为定性判定，检出即不合格。普通级与消毒级均不得检出。本卡输入各菌检出情况（0=未检出，1=检出），输出合格结论。注意此为判定逻辑，非浓度计算。
参考标准：GB 15979-2024《一次性使用卫生用品卫生要求》
