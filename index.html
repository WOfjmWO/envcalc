1环境空气和废气（含大气降尘）

分光光度法

废气 分光/比色标曲通用

计算公式（HJ 533/534/482/479/504/30、HJ/T 32、GB/T 15502、HJ 480、空气和废气监测分析方法第四版增补版）
C(mg/m³) = (A − A₀ − a) × Bs / Vnd
Bs 为计算因子（μg/吸光度），由标准曲线斜率倒数求得；a 为标准曲线截距（吸光度），标准计算中须扣除；Vnd 为标准状况采样体积（L），可由空气模块 A10 标况体积换算。硫化氢采用《空气和废气监测分析方法》（第四版 增补版）亚甲基蓝分光光度法（有组织废气见第五篇、无组织废气见第三篇）；氯气采用 HJ 30-1999 甲基橙分光光度法；酚类采用 HJ/T 32-1999 4-氨基安替比林分光光度法；苯胺类采用 GB/T 15502-1995 盐酸萘乙二胺分光光度法。覆盖氨（HJ 533-2009、HJ 534-2009《环境空气 氨的测定 次氯酸钠-水杨酸分光光度法》）、硫化氢、二氧化硫、氮氧化物、臭氧、氯气、酚类、苯胺类、氟化物等标曲反算型项目。

硫化氢 亚甲基蓝分光光度法（HJ 1388-2024）

计算公式（HJ 1388-2024 式(1)）
ρ(H₂S)(mg/m³) = (m₁ / V + m₂ / V) × 10.0 / Vnd × 34.08 / 32.06
m₁、m₂ 为第 1、2 支吸收管所取试样中硫化物（以 S²⁻ 计）的含量（μg），由标准曲线自动计算：m = (A − A₀ − a) / b × D（A₁、A₂ 为第 1、2 支试样显色液的吸光度，A₀ 为空白试验吸光度，a、b 为标准曲线截距、斜率（吸光度/μg），D 为稀释倍数）；m₁、m₂ 框为「自动 + 手动」两用：曲线参数（斜率/截距/空白/吸光度/稀释倍数）任一变动即按上式实时重算覆盖，也可直接手动输入含量值（手动输入后以手动值为准，直至曲线参数再次变动）；V 为每支吸收管所取试样体积（mL，两支取样体积相同，合并一框输入）；10.0 为吸收液体积（mL）；Vnd 为标准状态下干排气采样体积（L）；34.08/32.06 为 H₂S 与 S²⁻ 的摩尔质量比，结果以 H₂S 计。依据 HJ 1388-2024《固定污染源废气 硫化氢的测定 亚甲基蓝分光光度法》（2024-12-25 发布，2025-07-01 实施，首次发布），适用于固定污染源有组织排放废气；采样体积 10 L、吸收液体积 10 mL 时，方法检出限 0.007 mg/m³、测定下限 0.028 mg/m³；二氧化硫浓度大于 70 mg/m³ 或氮氧化物浓度大于 20 mg/m³ 时不适用本标准。
HJ 1388-2024《固定污染源废气 硫化氢的测定 亚甲基蓝分光光度法》（生态环境部 2024-12-25 批准发布，2025-07-01 实施）；原文见 mee.gov.cn。

金属 AAS/分光专项

计算公式（HJ 540-2016 / HJ 685-2014 / HJ 543-2009 / GB/T 7467-1987 / GB/T 11911-1989 / GB/T 11912-1989）
C = (A − A₀ − a) × D / (b × V)（铅按 HJ 685-2014 式(1)：ρ = ((A − a) × f − (A₀ − a)) / b × V定容 / Vnd）
通用式 C = (A − A₀ − a) × D / (b × V)，m = (A − A₀ − a) × D / b 为由标准曲线求得的待测物含量（μg），待输入体积 V 后给出浓度。砷 HJ 540-2016（二乙基二硫代氨基甲酸银分光光度法，代替 HJ 540-2009）：ρ(As) = (A − A₀ − a) / (b × Vnd)，b 单位吸光度/μg，Vnd 以 L 计，结果 mg/m³；铅 HJ 685-2014（石墨炉原子吸收法）：ρ(Pb) = ((A − a) × f − (A₀ − a)) / b × V定容 / Vnd，校准曲线以质量浓度(mg/L)计，全程序空白不乘稀释倍数 f，V定容 为试样定容体积(mL)，Vnd 以 L 计，结果 mg/m³；汞 HJ 543-2009（冷原子吸收法）：ρ(Hg) = (W₁ − W₀) × D / Vnd，曲线以汞含量(μg)计，D 含分取比 Vt/Va，结果 μg/m³；铬(六价) GB/T 7467-1987（二苯碳酰二肼分光光度法）：c = m / V，V 为试料体积(mL)，结果 mg/L；锰 GB/T 11911-1989、镍 GB/T 11912-1989（水质 火焰原子吸收分光光度法）：C = m / V，V 为分取水样体积(mL)，结果 mg/L。下拉选择元素用于切换方法说明、体积框语义与结果单位。
砷按 HJ 540-2016（二乙基二硫代氨基甲酸银分光光度法，代替 HJ 540-2009）：ρ(As) = (A − A₀ − a) / (b × Vnd)，Vnd 以 L 计，结果 mg/m³。

饮食业油烟（净化效率 / 浓度 / 基准折算）

计算公式（HJ 1077-2019 / GB 18483-2001）
排放浓度（HJ 1077-2019 式(6)）：ρ排(mg/m³) = ρ₁(mg/L) × V₁(mL) / Vnd(L)
基准折算（GB 18483-2001 6.6）：c基 = c测 × Q测 / (n × q基)，q基 = 2000 m³/h
净化效率（GB 18483-2001 5.3，按排放速率）：η = (Q前×C前 − Q后×C后) / (Q前×C前) × 100%
ρ₁ 为样品滤筒萃取液的质量浓度（mg/L）；V₁ 为萃取液体积（mL）；Vnd 为标准状态下干烟气采样体积（L，计算方法参照 GB/T 16157）；Q 为标干废气量（标准状态下干废气量，m³/h）。每个输入框均可输入多个数据（逗号或空格分隔），按位置一一对应计算（第 1 个数据对应第 1 个体积，以此类推），数据不足的样品不出结果。ρ排 浓度结果框为「自动 + 手动」两用：ρ₁、V₁、Vnd 齐全时自动计算填入，也可直接手动输入上机浓度结果（手动输入后以手动值为准；ρ₁、V₁、Vnd 任一参数改变后，结果框即按公式实时重算覆盖）。输入多个数据时，结果区最后输出平均值。结果保留位数按 HJ 1077-2019 9.3（与方法检出限一致，最多 3 位有效数字），进位按四舍六入五成双。基准折算判据 c基 ≤ 2.0 mg/m³（GB 18483-2001 表2，大中小型统一）。基准灶头数（总）n总 用于饮食业单位规模判定（GB 18483-2001 表1 按基准灶头数：小于 3 个为小型，3 个及以上且小于 6 个为中型，6 个及以上为大型）；基准灶头数（工作）n 用于基准折算（GB 18483-2001 6.6）。

氯化氢 HJ 549-2016（离子色谱法）

计算公式（HJ 549-2016 第10章）
ρ(HCl, mg/m³) = (ρ₁ + ρ₂ − 2ρ₀) × Vt / Vn × (36.45 / 35.45)

硫酸雾 HJ 544-2025（离子色谱法）

计算公式·有组织废气（HJ 544-2025 式(1)，2026-07-01 实施）
ρ(H₂SO₄)₁ = [(ρ₁ − ρ₀₁)×V′×D₁ + (ρ₂ − ρ₀₂)×V′×D₂] / (1000 × V″) × (98.08 / 96.06)
ρ₁ 为滤筒试样中 SO₄²⁻ 浓度（mg/L）；ρ₂ 为吸收瓶试样中 SO₄²⁻ 浓度（mg/L）；ρ₀₁/ρ₀₂ 为对应实验室空白平均浓度（mg/L，可缺省 0，标准式(2)/(3)由两支空白平均）；V′ 为试样定容体积（mL）；D₁/D₂ 为滤筒/吸收瓶试样稀释倍数；V″ 为按排放标准采用相应状态的采样体积（m³）；98.08/96.06 为 H₂SO₄/SO₄²⁻ 摩尔质量比。结果以 H₂SO₄ 计。
计算公式·无组织废气（HJ 544-2025 式(4)，2026-07-01 实施）
ρ(H₂SO₄)₂ = (ρ₁ − ρs)×V′×D / (1000 × V″) × (98.08 / 96.06)
ρ₁ 为滤膜试样中 SO₄²⁻ 浓度（mg/L）；ρs 为实验室空白滤膜试样硫酸根质量浓度平均值（mg/L），按标准式(5) ρs=(ρb₁+ρb₂)/2 由下方两支空白框自动平均（可缺省 0）；V′ 为试样定容体积（mL）；V″ 为按排放标准采用相应状态的采样体积（m³）；D 为试样稀释倍数；98.08/96.06 为 H₂SO₄/SO₄²⁻ 摩尔质量比。结果以 H₂SO₄ 计。

Vnd = V × 273/(273 + ts) × (Ba + Ps)/101.325
V 为累积流量计示值给出的实际采样体积(L)；ts 为流量计前气体温度(℃)；Ba 为大气压、Ps 为流量计前表压，单位均为 kPa。结果为 273 K、101.325 kPa 下的标况体积(L)，用于计算颗粒物与气态污染物浓度。
崂应3012H-D说明书式(4)；Ba、Ps单位 kPa，标准 101.325 kPa

烟气工况流量（崂应式5）

计算公式（崂应 3012H-D 式5 · 工况烟气流量，GB/T 16157-1996）
Qs = 3600 × Vs × F
Vs 为烟道测定断面的平均流速(m/s)，F 为烟道断面积(m²)，系数 3600 为 s→h 换算，结果为工况湿烟气流量(m³/h)。断面积应按实测内径计算，圆形烟道 F = πD2/4。
崂应3012H-D说明书式(5)；Qs单位 m³/h

标干烟气流量（崂应式6）

计算公式（崂应 3012H-D 式6 · 标干烟气流量，GB/T 16157-1996）
Qsnd = Qs × 273/(273 + ts) × (Ba + Ps)/101.325 × (1 − Xsw)
Qs 工况湿烟气流量(m³/h)；Ba、Ps 单位为 kPa；Xsw 以百分数(%)输入，程序内部按 (1 − Xsw/100) 计算。标干流量是核算污染物排放速率与排放量的基准流量。
崂应3012H-D说明书式(6)；Xsw以%输入按(1−Xsw/100)计
7烟气流速与采样参数（含 HJ 1405-2024）

烟气流速（皮托管 崂应式11）

计算公式（崂应 3012H-D 式11 · 皮托管法烟气流速，GB/T 16157-1996）
Vs = Kp × √( 2 Pd / ρ ) = 1.414 × Kp × √( Pd / ρ )
Kp 为皮托管系数（S 型约 0.84，标准型约 1.00，以校正证书为准）；Pd 为动压(Pa)；ρ 为工况烟气密度(kg/m³)。断面平均流速应先对各测点的 √Pd 求算术平均，再代入本式计算，不可先平均 Pd。
崂应3012H-D说明书式(11)；ρ可由"烟气密度"计算器求得

烟气密度（崂应式12）

计算公式（崂应 3012H-D 式12 · 工况烟气密度）
ρ = 1.34 × (Ba + Ps)/101.325 × 273/(273 + ts)
1.34 kg/m³ 为标准状态下一般燃烧烟气的近似密度。当烟气组分与空气差异较大（如高 CO2、高湿或含大量惰性气体）时，应先按实测组分计算标况密度 ρn 再代入。Ba、Ps 单位为 kPa。
崂应3012H-D说明书式(12)；1.34 为烟气密度系数(kg/m³, 标准状态)

静压计算（崂应式8）

计算公式（崂应 3012H-D 式8 · 烟道静压）
Ps = Pt − Kp × Pd / 1000
Pt 为全压(kPa)，Pd 为动压(Pa)，除以 1000 换算为 kPa 后相减。Ps 为负值表示烟道内处于负压状态（引风机在测点下游），此时标况换算中的 (Ba + Ps) 将小于大气压。
崂应3012H-D说明书式(8)；Ps单位 kPa

等速采样流量/采样嘴直径

计算公式（崂应式9/10 · 等速采样流量与采样嘴直径，GB/T 16157-1996）
等速采样流量：Qrs = 0.047 × Vs × d2 × (1 − Xsw)
采样嘴直径（由上式反解）：d = √[ Qrs / ( 0.047 × Vs × (1 − Xsw) ) ]
Vs 烟气流速(m/s)、d 采样嘴内径(mm)、Qrs 流量计前干气体流量(L/min)、Xsw 以百分数(%)输入。等速采样相对偏差应控制在 ±10% 以内。
崂应3012H-D说明书式(9)/(10)；Xsw以%输入按(1−Xsw/100)计

流速均方差（HJ 1405-2024）

计算公式（流速相对均方差 σr 与变异系数 · HJ 1405-2024 §4.2.4）
平均流速 v̄ = (1/n) ∑ vi
绝对标准差 s = √[ ∑(vi − v̄)2 / (n − 1) ]
流速相对均方差 σr = s / v̄ = √[ ∑(vi − v̄)2 / ((n − 1) × v̄2) ]
变异系数 CV = s / v̄ × 100%   判据：σr ≤ 0.15（HJ 1405-2024 §4.2.4）
用于评价烟道测定断面的流速分布均匀性。HJ 1405-2024 §4.2.4 以"流速相对均方差 σr"（无量纲）判定：σr > 0.15 表明流场不稳定或存在涡流，应增加测点数、延长直管段或另选监测断面，否则等速采样与流量核算结果代表性不足。σr = s / v̄ = CV / 100。注：HJ 1405-2024 自 2027-01-01 实施，过渡期内 GB/T 16157、HJ/T 397 关于采样位置与测点的要求仍适用。
参考 HJ 1405-2024 §4.2.4：σr 为流速相对均方差(无量纲)，s 为绝对标准差，CV 为变异系数(均匀度评估)

排放速率计算

计算公式（污染物排放速率 · GB/T 16157-1996 / GB 16297-1996）
G = C × Qsnd × 10−6  (kg/h)
C 为标态干基排放浓度(mg/m³)，Qsnd 为标态干烟气流量(m³/h)，10−6 为 mg → kg 的换算系数。所得排放速率须与 GB 16297-1996 表2（或行业排放标准）中按排气筒高度确定的最高允许排放速率比较后判定达标情况。
参考标准：HJ/T 397-2007；GB/T 16157-1996

实测烟尘浓度（崂应式7，恒重法）

计算公式（崂应 3012H-D 式7 · 实测烟尘浓度，GB/T 16157-1996 / HJ 836-2017）
C = ( m̄后 − m̄前 ) × 106 / Vnd
恒重判定：|m前1−m前2| ≤ 允差 且 |m后1−m后2| ≤ 允差
m前1/m前2、m后1/m后2 为采样前后滤筒各 2 次恒重称量质量（单位 g）；Vnd 为标况采样体积（L）；106 为 g/L → mg/m³ 换算系数。天平精度可选：HJ 836-2017 低浓度颗粒物两次称量差≤0.20 mg（0.0002 g）、十万分之一天平恒重允差 0.0004 g、万分之一天平 0.0010 g。恒重不合格时不输出浓度，须继续干燥至恒重。
0.0002 g = HJ 836 低浓度颗粒物（两次恒重差 ≤0.20 mg）；0.0004 g = 十万分之一天平（≤0.4 mg）；0.0010 g = 万分之一天平（≤1.0 mg）
崂应3012H-D说明书式(7)；C 单位 mg/m³；恒重程序按 HJ 836-2017

烟尘排放量（崂应式14）

计算公式（崂应 3012H-D 式14 · 烟尘排放量）
G = C × Qsnd × 10−6  (kg/h)
C 为实测烟尘浓度(mg/m³)，Qsnd 为标干烟气流量(m³/h)。核算时段排放总量按 W = G × T（T 为该工况实际运行小时数）累加；若有多个工况，应分别核算后求和。
崂应3012H-D说明书式(14)；G 单位 kg/h
8浓度与体积分数换算（mg/m³ ↔ ppm ↔ %）

浓度 ↔ 体积分数换算

换算公式（质量浓度 ↔ 体积分数 · 理想气体状态方程）
ppm = C(mg/m³) × Vm × (273.15 + t)/Tref × 101.325/P ÷ M
C(mg/m³) = ppm × M ÷ [ Vm × (273.15 + t)/Tref × 101.325/P ]
vol% = ppm / 10000
Vm：标准状态 = 22.414 L/mol（Tref=273.15 K）；参比状态 = 24.465 L/mol（Tref=298.15 K，常取 24.5）
M 为摩尔质量(g/mol)，t 为温度(℃)，P 为大气压(kPa)。22.414 L/mol 是标准状态(0℃,101.325kPa)下的气体摩尔体积；24.465 L/mol（常取 24.5）是参比状态(25℃,101.325kPa)下的气体摩尔体积，二者均来自理想气体状态方程 RT/P，仅温度基准不同，都不是万能常数：计算时按所选"状态基准"取用对应 Vm 与 Tref，并保留 (273.15+t)/Tref × 101.325/P 温压修正因子（t=0、P=101.325 时化简）。注意：污染物排放标准中的 mg/m³ 通常指标准状态干基浓度，换算前应先完成状态与干基折算。
适用 SO₂、NO₂、NO、H₂S、CH₄、NH₃、CO、CO₂、O₂ 等；标准状态(0℃,101.325kPa)摩尔体积 22.414 L/mol，参比状态(25℃,101.325kPa)摩尔体积 24.465 L/mol（常取 24.5）；按所选"状态基准"取用，并保留温压修正。

干基浓度值换算

换算公式（湿基 → 干基 · 质量守恒法）
C干 = C实测 / (1 − Xsw/100)
推导（质量守恒）：烟气中污染物质量 m = C湿×V湿 = C干×V干，其中干烟气体积 V干 = V湿×(1−Xsw/100)，代入得 C干 = C湿/(1−Xsw/100)
公式出处（现行有效，已在线核实）：HJ 1240-2021《固定污染源废气 气态污染物（SO₂、NO、NO₂、CO、CO₂）的测定 便携式傅立叶变换红外光谱法》（生态环境部 2021-12-30 发布、2022-06-01 实施）§10.1 结果计算 公式(3)：ρ = ρ′ × 1/(1−φsw)——仪器示值为质量浓度时，湿基浓度换算为标准状态下干基废气质量浓度，φsw 为废气中水分的体积分数（%）；同标准公式(4) NOx 换算同式。CEMS 数据处理体系通用的 DustG = Dust/(1−Xsw/100)（干基值）与之等价。Xsw 为排气中水分含量体积百分数，按 GB/T 16157-1996 §5.2.2（冷凝法/重量法）等测定。使用前提：C实测 与 C干 须基于同一温度/压力基准（如同为标准状态 0℃）；Xsw=0 时即为干烟气，C干=C实测；排放标准的基准氧含量折算应在干基浓度基础上进行。
湿基浓度 → 干基浓度：C干 = C实测/(1−Xsw/100)。依据 HJ 1240-2021 §10.1 公式(3)；Xsw 为排气中水分含量体积百分数（GB/T 16157-1996 §5.2.2）。Xsw=0 时 C干=C实测；Xsw≥100 无物理意义（干烟气体积为 0）。
9仪器校准（绝对误差 / 示值误差）

气体浓度校准（绝对/示值误差）

计算公式（气体分析仪示值误差 · HJ 57 / HJ 693 / GB/T 16157）
绝对误差 Δ = X测 − X标
示值误差（相对标准值）= (X测 − X标) / X标 × 100%
单位换算：C(μmol/mol) = C(mg/m³) × 22.4 / M
判定（HJ 57 / HJ 693）：
  C标 ≥ 100 μmol/mol → 允差 ≤ ±5%（相对标准值）
  C标 < 100 μmol/mol → 允差 ≤ ±5 μmol/mol（绝对）
M 为污染物气体分子量（下拉选择常用气体，含自定义手输）；22.4 为标准状态（0℃、101.325 kPa）摩尔体积 L/mol。标准气体浓度 ≥ 100 μmol/mol 时按相对标准值 ±5% 判定；< 100 μmol/mol 时按绝对误差 ±5 μmol/mol 判定（依据 HJ 57、HJ 693 示值误差性能要求，不再统一执行 ±5%）。
参考 HJ 57(SO₂)、HJ 693(NOx)、HJ 870(CO)、HJ 973、HJ 397；示值误差按标准气体浓度分段判定：≥100 μmol/mol ≤±5%，<100 μmol/mol ≤±5 μmol/mol；满量程挡位为常用参考值，可选择或手输

通用仪器校准（误差类）

计算公式（误差评定通则 · JJF 1059.1-2012 / 各仪器检定规程）
绝对误差 Δ = x测 − x标
相对误差 δ = Δ / x标 × 100%
引用误差 γ = Δ / FS × 100%  (FS 为仪器满量程)
判定：|δ| ≤ 允许误差限 为合格
引用误差用于评价按量程分级的仪表（压力表、流量计、电流表等），相对误差用于评价具体示值。允许误差限须取自对应仪器的检定规程、校准规范或方法标准，不可自定。下拉挡位取自检定规程准确度等级系列（现行有效）：电流表/电压表/功率表 0.1、0.2、0.5、1.0、1.5、2.0、2.5、5.0 级（JJG 124-2005 表1，最大允许误差=等级%，即引用误差）；一般压力表 1.0、1.6（1.5）、2.5、4.0 级（JJG 52-2013 表1，按量程%计算）。挡位覆盖其中常用值，未列入的等级或方法标准规定值可直接手输。

压力传感器示值误差

计算公式（崂应 3012H-D 式1 · 压力示值误差）
ΔP = (P1 − P0) − Ps
P1 为仪器显示压力，P0 为当前实际大气压，二者之差即仪器指示的表压；Ps 为标准压力源给出的标准表压值。按仪器说明书，压力/大气压传感器标定允差取 ±0.5 kPa，|ΔP| 超出即判不合格，应重新标定。各量单位统一为 kPa。

单项水质标准指数

计算公式（单项水质标准指数 · HJ 2.3-2018 / GB 3838-2002）
Ii = Ci / C0i
判定：Ii ≤ 1 达标；Ii > 1 超标
Ci 为第 i 项污染物实测浓度，C0i 为该项在评价水质类别下的标准限值（地表水取 GB 3838-2002，污水排放取 GB 8978-1996 或行业标准）。pH、溶解氧、水温等非“浓度越低越好”的指标不适用本式，应分别使用 pH 标准指数与 DO 标准指数。

pH 标准指数

计算公式（pH 标准指数 · HJ 2.3-2018）
pH ≤ 7.0 时：IpH = (7.0 − pH) / (7.0 − pHsd)
pH > 7.0 时：IpH = (pH − 7.0) / (pHsu − 7.0)
pHsd、pHsu 分别为标准规定的 pH 下限与上限（GB 3838-2002 地表水为 6~9）。IpH ≤ 1 表示达标；因 pH 为对数量且存在双侧限值，不能直接用 C/C0 形式计算。

溶解氧(DO)标准指数

计算公式（溶解氧标准指数 · HJ 2.3-2018）
饱和溶解氧 Cf = 468 / (31.6 + T)  (T 为水温 ℃)

DO < Cs 时：SDO = 10 − 9 × DO / Cs
Cs 为溶解氧标准限值(mg/L)。Cf 为不含盐度与气压修正的饱和溶解氧近似式，高海拔或咸水水体应另行修正。SDO ≤ 1 为达标；DO 属“越大越好”指标，故指数形式与一般污染物相反。
参考标准：GB 3838-2002；Cf 近似式适用于淡水 1 atm，精算需查饱和溶解氧表；标准指数公式依据 HJ 2.3-2018《环境影响评价技术导则 地表水环境》

计算公式（电位 → pH 换算 · Nernst 方程）
pH = pHiso + ( Eiso − E ) / S
自动斜率 S = 59.16 × (T + 273.15) / 298.15  (mV/pH)
电极效率 = S实用 / S理论 × 100%，合格区间 95% ~ 105%
pHiso 与 Eiso 为定位（等电位）点的 pH 与电位，通常以 pH 6.86 缓冲液定位，理想电极此点电位接近 0 mV。若计算 pH 超出 0~14 量程，应检查电位符号、定位点取值与电极状态。
GB/T 6920-1986 玻璃电极法：以pH7缓冲液定位，pH = pHiso + (Eiso − E)/S；斜率S按Nernst方程随温度变化，25℃为59.16 mV/pH。电极斜率应在理论值的95%~105%之间

水质浓度换算

换算公式（质量浓度 / 摩尔浓度 / 以元素计）
摩尔浓度 c(mmol/L) = ρ(mg/L) / M(g/mol)
以元素计 ρ元素 = ρ化合物 × f   f = M元素 / M化合物
常见换算因子：NO3− 以 N 计 f = 14/62 = 0.2259；NH4+ 以 N 计 f = 14/18 = 0.7778；SO42− 以 S 计 f = 32/96 = 0.3333；PO43− 以 P 计 f = 31/95 = 0.3263。程序已内置常见指标的 M 与 f，选择指标后自动换算。报出结果时必须注明计量基准（以 N 计 / 以化合物计）。

计算公式（稳定流抽水试验 · Thiem/裘布依 · GB/T 50027-2024 / DZ/T 0288-2015）

计算公式（稀释接种法 · HJ 505-2009 / GB/T 5750.7）

计算公式（背景噪声修正 · HJ 706-2014 / GB 12348-2008 附录A）
ΔL = L总 − L背
ΔL < 3 dB → 测量无效，须降低背景噪声后重测

ΔL ≥ 10 dB → 修正量 < 0.5 dB，取 L = L总
L总 为声源与背景同时存在时的测量值，L背 为声源停止运行后的本底值，两者测点、档位、时长应完全一致。修正结果按标准要求取整到个位。

计算公式（最小二乘一元线性回归 · 校准曲线）

精密度与准确度统计

计算公式（精密度与准确度统计）
均值 x̄ = (1/n) ∑ xi
标准偏差 s = √[ ∑(xi − x̄)2 / (n − 1) ]
相对标准偏差 RSD = s / x̄ × 100%   极差 R = xmax − xmin
绝对误差 = x̄ − xref   相对误差 = (x̄ − xref) / xref × 100%
RSD 表征精密度，相对误差表征准确度。xref 为标准物质认定值或约定真值，留空时仅输出精密度统计量。s 采用样本标准偏差（分母 n−1），n ≥ 2。
精密度：RSD(相对标准偏差)；准确度：绝对误差/相对误差/相对偏差

相对误差与相对偏差

计算公式（相对误差与相对偏差）
相对误差 RE = ( x1 − x2 ) / x2 × 100%  (x2 为标准值 / 参考值)
相对偏差 RD = | x1 − x2 | / [ ( x1 + x2 ) / 2 ] × 100%
RE 评价单次测定结果偏离标准值的准确度；RD 评价两次平行测定之间的精密度。平行双样相对偏差一般要求 ≤ 10%（低浓度样品可放宽至 20%~30%），具体以方法标准规定为准。

重复性计算

计算公式（重复性 / 实验室内精密度）
x̄ = (1/n) ∑ xi
s = √[ ∑(xi − x̄)2 / (n − 1) ]
RSD = s / |x̄| × 100%   极差 R = xmax − xmin

检出限与测定下限

计算公式（方法检出限与测定下限 · HJ 168-2020 附录A）
s = √[ ∑( xi − x̄ )2 / ( n − 1 ) ]
MDL = t(n−1, 0.99) × s
测定下限 = 4 × MDL
对浓度约为估计检出限 1~5 倍的空白加标样品平行测定 n ≥ 7 次；t 为自由度 n−1、置信度 99% 的单侧 t 值（n = 7 时 t = 3.143，n = 8 时 t = 2.998）。计算所得 MDL 应不大于方法标准规定值，否则须查找原因并重新验证。
输入空白(或低浓度)样品的多次重复测定值，逗号/空格/换行分隔
建议 n=7，t(0.99,6)=3.143

精密度（RSD）

计算公式（方法精密度 RSD · HJ 168-2020）
x̄ = (1/n) ∑ xi
s = √[ ∑( xi − x̄ )2 / ( n − 1 ) ]
RSD = s / x̄ × 100%
方法验证要求对低、中、高三个浓度水平的样品各平行测定 6~7 次，分别计算 RSD，结果均应满足方法标准规定的精密度指标。低浓度水平的 RSD 允许值通常较高浓度宽松。
输入一组平行测定结果，用英文逗号/空格/换行分隔。

准确度（标准物质 RE）

计算公式（方法准确度 · 有证标准物质 RE，HJ 168-2020）
RE = ( x̄ − μ ) / μ × 100%
x̄ 为对有证标准物质平行测定 6 次的均值，μ 为标准物质认定值。判定：|RE| 应落在标准物质给出的不确定度区间内，或满足方法标准规定的准确度要求。无适用标准物质时，改用基体加标回收率评价准确度。
